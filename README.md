# Blackjack Strategy Simulation

## Overview
This project is a simulation of a 2 through 6-deck blackjack game built in Python.

The simulation evaluates:
- Simple Strategy
- Basic Strategy
- Hi-Lo Card Counting Strategy

## Objective
To analyze expected value and bankroll volatility across 10,000+ simulated hands and 50 iteractions.

## Features
- Object-Oriented blackjack engine
- True count calculation
- Running count tracking
- Multi-deck shoe simulation
- Bankroll tracking
- Strategy comparison
- Blackjack game play with Hi-Lo Card Counting and Basic Strategy guidance

## Results
Card counting strategy shows positive expected value over large sample sizes, while simple strategy produces long-term losses.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Math
- Statistics
